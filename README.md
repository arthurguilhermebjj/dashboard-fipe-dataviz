# Dashboard de Análise de Veículos da Tabela FIPE

## Sobre o Projeto

Este projeto foi desenvolvido como atividade final da disciplina **DataViz: Ferramentas para Visualização de Dados**, da Especialização em Análise de Dados e Inteligência Artificial da CESAR School.

O objetivo do trabalho foi realizar o tratamento, análise e visualização de dados da Tabela FIPE, utilizando Excel para preparação dos dados e Google Looker Studio para construção do dashboard.

## Objetivos

- Realizar limpeza e tratamento da base de dados.
- Identificar padrões relacionados às marcas de veículos.
- Analisar preços médios por fabricante.
- Comparar tipos de combustível e tipos de câmbio.
- Construir um dashboard interativo para apoiar a interpretação dos dados.

## Ferramentas Utilizadas

- Microsoft Excel
- Google Looker Studio
- GitHub

## Principais Insights

### Quantidade de veículos

- Fiat e Volkswagen apresentaram as maiores quantidades de veículos na base analisada.
- Nissan apresentou a menor quantidade de registros.

### Tipo de câmbio

- Os veículos com câmbio manual predominam na base de dados.

### Combustível

- A gasolina é o combustível predominante entre os veículos analisados.

### Preço médio

- A Nissan apresentou o maior preço médio entre as marcas analisadas.
- Veículos automáticos possuem preços médios superiores aos veículos manuais na maioria das marcas.
- Veículos movidos a diesel apresentaram os maiores preços médios quando comparados aos movidos a gasolina e álcool.
